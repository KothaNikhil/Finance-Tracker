Proposed (not built). Only one device edits at a time. A lock file in Drive (finance-session.json) names the device that is editing. That device refreshes it every minute, and it expires after 3 minutes without a refresh. Every other device is view only until it takes over. Backend: packages/core/src/sync/lock.ts. Website versions: Website mocks → Drive status → “One device edits at a time”.
