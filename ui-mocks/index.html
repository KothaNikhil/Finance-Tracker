WORKING WITH THESE MOCKS

  • assets/mock.css mirrors mobile/src/constants/theme.ts (colours, spacing, radius) and the ThemedText type scale. When a token changes in one place, change it in the other.
  • Use only the CSS variables for colour and keep font weight at 500 or below, as the app does.
  • Icons are Material Symbols, using the Android/web names the app passes to SymbolView.
  • Start a new screen from _template.html. Show one phone frame per state, sheet or dialog.
  • The mocks need no build step or backend. Open any file in a browser. Fonts and icons load from Google Fonts.
